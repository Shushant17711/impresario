# Historical direction — not current skill rules

See `README.md`: original constraints below are history, not universal rendering rules or proof of delivery.

- **Concept:** a single fight read as stills; the camera does not cut.
- **Tone:** austere, ceremonial, patient.
- **Palette:** ink #0e0f0c, paper #f2efe6, ash #6e7a5e, ember #c8452a.
- **Type:** display "Iowan Old Style"; text "Iowan Old Style"; data "Iowan Old Style".
- **Scale:** 72 / 40 / 24 / 17 / 13.
- **Spacing:** 4, 8, 16, 32, 64, 96, 160.
- **Composition:** single column, 640px measure, scenes pinned full-bleed.
- **Motion:** one pinned scene per beat, transform and opacity only, scrub 0.6,
  breathing room 0.2 at each end. Lenis on. Reduced motion: static stills.
- **Image:** grain overlay at 6% opacity, no blur, no shadow.
- **Avoid:** gradients, neon, glow, emoji, stock phrases, hero-with-floating-card.
- **Signature:** the mask that opens on a line of text, one per scene.
