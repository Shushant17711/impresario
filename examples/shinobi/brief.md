# Historical brief — not delivered by index.html

See `README.md`: this is a mechanics-only negative example, not accepted creative work.

## User request

"Build a shinobi scroll-driven site: a long take through a single fight, with
pinned scenes and a character reveal. Stack: HTML, GSAP, Lenis, reduced motion."

## Constraints

- One page. Scroll is the narrative.
- No scroll hijacking: native scroll, Lenis as a smoothing layer only.
- Reduced motion shows the same content, static.
- No stock phrases, no hero-with-gradient, no emoji icons.

## Deliverables

- `index.html` — the page.
- `concept.md` — the one-line concept.
- `direction.md` — the direction sheet.
- `storyboard.md` — the scene list with progress mappings.
- Screenshots from `scenes.mjs` at desktop and phone.
