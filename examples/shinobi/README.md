# Shinobi — mechanics-only prototype, not accepted creative work

This retained example demonstrates a GSAP/ScrollTrigger pin and two small DOM transforms.
It does **not** implement the character, sword draw, comic choreography, asset fidelity
or substantially different compositions promised by its original brief and planning docs.

The translucent rectangles translate 8%; a thin line grows. These are placeholders and
supporting mechanics, not a cinematic showpiece. The original concept/direction/storyboard
are historical plans, not evidence of delivery. Do not copy this implementation as a
reference-quality result or call it an accepted living comic.

A finished direction would require actual illustrated/articulated subject assets, a
useful/narrative transformation and independent desktop/mobile review. Consult
`../../references/reference-translations.md` and `../../references/evidence.md`.
