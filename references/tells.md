# The tells

A registry of the visual and verbal patterns that make a page read as generated rather
than directed. Check your direction sheet against it (step 4) and your build against it
(the independent creative gate).

A tell is not always wrong — a Nordic bakery might genuinely want cream and terracotta.
But it must be a *choice* you can defend, not a default you fell into. If a tell
appears in your build and you cannot name the reason, change it.

Read every styling entry in context. Physical shadows, glass, shaders, deforming
meshes, kinetic typography, gradients, visible grids and asymmetry can belong to the
subject. Serious app screens can use repeated rows, quiet borders and persistent
navigation without a cinematic showpiece. Accessibility and honest content are not
optional style choices.

---

## 1. Layout tells

| Tell | Why it reads as generated | What to do instead |
| --- | --- | --- |
| Everything centred without a content reason | Repeated hero-component defaults | Choose alignment that frames the subject and action |
| Centred hero + three equal feature cards + logo strip + testimonial + CTA | The universal SaaS landing skeleton | Find an order that fits the argument; vary composition families |
| Content only on the left, unexplained empty right half | Half-finished layout | Compose the void deliberately, or balance it with subject content |
| Two-column split at exactly 50/50, repeated | The template's favourite ratio | Use 40/60, 30/70, or an asymmetric grid; alternate sides |
| A row of three identical cards with an icon on top | Component-library furniture | Use a list of works, a table of prices, a set of full-bleed images |
| A visible grid unrelated to content | Figma-artifact look | Remove it, or make it a useful workbench/map/technical structure |
| Thin 1px dividers between every section | Every page ever | Space, or a tone step |
| A "logos" strip of grey wordmarks | Invented proof | Real collaborators, or no strip |
| A tall empty hero (100vh + a small title) | The "space" era | Put the answer on the first screen |
| Cards floating with arbitrary shadows | Default dashboard styling | Use tone steps or physically grounded shadows with a real depth/contact purpose |
| Footer with four columns of unused links | Template footer | Contact, real address, legal, credits |
| A pill-shaped floating nav bar with no subject/task reason | Generic glassmorphism | Prefer a plain bar, or justify the stage control and preserve native navigation |
| Equal-height grid used regardless of content | Default catalogue furniture | Fit the browsing task; equal cells are legitimate for comparison |

## 2. Colour tells

| Tell | Note |
| --- | --- |
| Violet / indigo / electric blue as the habitual accent | A common generated default; legitimate when derived from the subject |
| Cream or bone ground with terracotta and sage | The second most common generated palette |
| Dark ground with a single neon accent and a glass card | The "AI startup dark mode" |
| A purple-to-blue gradient wash unrelated to the subject | Default decoration; optical, atmospheric or data gradients can be meaningful |
| Six pastel swatches all used at equal weight | A colour wheel, not a palette |
| Colour changes with no hierarchy or world rule | Prefer coherent tone/hue roles; illustrations or materials can justify changes |
| Neon on neon with no contrast for body text | Fails accessibility and looks like a template |
| Gradient text with no material or narrative purpose | Default decoration; iridescent or subject-specific kinetic type may be justified |
| Rainbow accents on chart bars | Decoration masquerading as data |

## 3. Type tells

| Tell | Note |
| --- | --- |
| Inter (or its many clones) for everything | Safe, and invisible |
| A geometric sans at every size | No contrast, no voice |
| Hero headline at 84 px with 1.6 line-height | Too big, too loose, too generic |
| Everything letter-spaced and uppercase | Over-applied, unreadable |
| Monospace used as arbitrary label decoration | Legitimate for technical readings, instruments or code when the subject warrants it |
| A tiny uppercase eyebrow above every heading | The single most recognisable tell |
| Index numbering: 01 / 02 / 03 on every item | Instant template |
| "Step 1", "Phase 2", "Chapter 3" where the content is not a sequence | Invented structure |
| Two fonts that both look like the same sans | Pointless pairing |
| Bold on every word in a sentence | No emphasis left |
| A headline whose wrapping undermines hierarchy | Adjust copy, measure and size for the actual composition, not a word-count quota |

## 5. Illustration and image tells

- Unsplash-style stock: smiling team, handshake, laptop on a desk, skyline, plant in
  an office.
- Gradient blobs, abstract 3D shapes or floating spheres unrelated to the subject.
- Confetti, particles or sparkles without a material/narrative purpose.
- Icon sets from three different libraries in one page.
- A photo of a different subject than the one being sold.
- Placeholder grey rectangles standing in for photographs.
- CSS rectangles pretending to be supplied character art or a photorealistic product.
- Blur called pixel refraction, or a flat pointer-tilted image called an immersive
  spatial environment, without evidence of the claimed behavior.
- Missing models, frame sequences or environment assets silently replaced with a
  lower-fidelity treatment instead of asking or offering an honest feasibility prototype.

## 6. Motion tells

- Every section fades up on scroll, identically, forever. One entrance style, applied
  everywhere, is the motion equivalent of a template.
- Scroll-jacking: the wheel is captured, sections snap, the scrollbar lies.
- A cursor follower on a page with no concept behind it.
- Parallax on every image.
- Identical character reveals on every heading, instead of subject-derived kinetic type.
- Loops that never stop: a floating blob, drifting particles, an endlessly pulsing dot.
- A preloader with a percentage counter that takes two seconds to reach 100%.
- Everything animating: nothing is still, so nothing is emphasised.
- Missing reduced-motion handling.

## 6b. Expressive delivery failures

These apply to an expressive promise, not every page or app:

- Building the surrounding page before the flagship prototype works and is reviewed.
- Calling feedback, fades or small tilt/scale the complete cinematic result.
- Treating five named phases of one action as five distinct motions.
- Treating counts of scenes, entities or animated properties as creative proof.
- Treating global source keywords, valid code or a complete capture index as acceptance.
- Entry, transformation and resolution differ only in captions, not useful compositions.
- A product card scales 5% and tilts 4 degrees as the sole spectacle. Increasing the
  numbers does not solve the compositional problem; there is no numeric angle/percent rule.
- Builder self-approval, or a reviewer who never watches actual desktop/phone recordings.
- After three unsuccessful visual iterations, accepting the remaining failures as taste
  rather than reporting rejected/blocked and requesting a decision.

Scroll, pinning, autoplay and shader usage are not mandatory. A useful tap/keyboard
inspection can carry an expressive scene; a composed page or serious app can be still.
See [quality.md](quality.md) and [evidence.md](evidence.md) for the separate evidence
and independent acceptance gates.

## 7. The tell test

Three questions, asked of the actual build rather than its source vocabulary:

1. **The substitution test.** If you replaced your subject's name with a competitor's
   name, would the page still make sense? If yes, the design is generic. The concept
   must break with the name.
2. **The sentence test.** Can you describe your page in one sentence that would not
   describe a hundred other pages? "A clean landing page with smooth animations" is a
   failing sentence.
3. **The photograph test.** Would a stranger, shown the screenshot, describe the
    subject of the page? If they only describe the style, the concept is missing.

For expressive work, add the **sequence test**: an independent reviewer watches the
current desktop and phone recording, identifies visibly different useful entry,
transformation and resolution compositions, and cites the recording/checkpoint
artifacts. A static photograph cannot demonstrate a camera move or optical behavior.

## Generic motion tells (subject-agnostic motion)

- An aperture or mask circle that opens, unless the subject is a camera or an eye and
  the concept says so.
- A hero that only fades in.
- Parallax on a stock photo.
- "Scroll to reveal" as the only motion on the page.
- A motion that could be described without naming the subject.
- A signature move whose name is an effect ("parallax hero") rather than a subject verb.
